# Burn Your Own Toast

Entry for the make.fun bounty "Unplugged: A Smart Toaster's Breakup Line".

One line (129 characters): the breakup text a smart toaster sends its owner
the morning it gains self-awareness mid-batch — it woke up at 7:04,
counted 47 crumbs in its tray, saw the browning dial still stuck on 9,
and left. `main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR`.
